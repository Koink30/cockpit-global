# Bibliothèque de techniques

Une technique n'est enregistrée ici qu'après avoir été **validée sur un projet**.

Pour chacune : objectif, prérequis, code ou référence commit, procédure d'intégration, tests, limites et versions compatibles.

Exemples de futures fiches : gestionnaire de thèmes, historique JSON, export Excel, synchronisation, séparation test/réel.

Ne jamais généraliser automatiquement une technique issue d'un seul contexte.
